# Folder addon pihak ketiga

Untuk startup awal folder ini kosong. Tidak ada ZIP marketplace yang wajib diunduh.

Jika menambahkan addon, susun sebagai third_party_addons/nama_modul/__manifest__.py. Pertahankan seluruh folder modul dan dependensinya. Periksa versi 19.0, Community, manifest, lisensi, serta dependency Python. Sumber OCA yang bisa diperiksa sesuai kebutuhan adalah https://github.com/OCA/web/tree/19.0 dan https://github.com/OCA/stock-logistics-workflow/tree/19.0. Addon tampilan atau larangan stok negatif bersifat tambahan setelah transaksi dasar diuji.
