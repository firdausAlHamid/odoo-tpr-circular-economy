# Folder addon penelitian

Folder berikut adalah tempat pengembangan. Belum berisi addon yang bisa diinstal.

| Folder | Fungsi yang direncanakan |
|---|---|
| tpr_circular_core | Data material satuan metadata dan hubungan sumber transaksi |
| tpr_waste_management | Identitas potongan pemeriksaan reuse penyaluran dan MFA |
| tpr_manufacturing_ce | Usulan pemakaian bahan produksi untuk dibahas dengan Feriangga |
| tpr_circular_dashboard | Tampilan dan laporan untuk dua fokus penelitian |

Antigravity akan membuat __init__.py, __manifest__.py, models, views, security, data, dan tests sesuai tahap pengembangan. Core tidak bergantung pada dua addon penelitian. Dashboard dapat bergantung pada addon yang sudah selesai dan diuji.
